# Contratos · 001-agentes-codex

No hay contrato de red. El contrato de fichero de cada agente Codex exige:

- `name`: nombre exacto del perfil canónico;
- `description`: criterio de selección del agente;
- `developer_instructions`: referencia explícita a `.claude/agents/<name>.md`;
- `sandbox_mode = "read-only"` para los cuatro roles auditores definidos por la constitución.

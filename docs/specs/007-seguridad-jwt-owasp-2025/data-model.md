# Modelo de datos · 007-seguridad-jwt-owasp-2025

No hay esquema de aplicación ni migración. El modelo documental incorpora:

- Control local estable (`SEC-*`).
- Referencia versionada a ASVS/OWASP.
- Aplicabilidad y justificación.
- Decisión, tarea, test y evidencia.
- Informe: estándar, nivel, alcance, conteos, veredicto y riesgos aceptados.

Compatibilidad: las specs históricas se preservan; el contrato estricto se aplica a specs nuevas
sensibles y a las históricas cuando se migren explícitamente.

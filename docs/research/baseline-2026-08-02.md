# Baseline · Agent Skills portable · 2026-08-02

## Alcance

Revalidación puntual del formato Agent Skills, el CLI `npx skills`, la ubicación portable por
proyecto y la skill oficial `skill-creator`. No revalida el resto de IDE, hooks, MCP o seguridad.

## Hallazgos

| Clasificación | Hallazgo | Decisión |
|---|---|---|
| ruptura | Trece skills canónicas contenían `disable-model-invocation`, campo propio de Claude y ajeno al estándar | moverlo a `.claude/skills/` y bloquearlo en el gate canónico |
| compatible | `.agents/skills/` es ruta de proyecto para Universal, Codex, Cursor, Copilot, Antigravity y otros clientes | mantenerla como fuente canónica |
| compatible | Claude Code usa `.claude/skills/` | mantener adaptadores planos, sin symlinks |
| mejora | `skill-creator` aporta validación, evals, benchmark y empaquetado | vendorizar completa, con licencia y commit fijados |
| riesgo | Sus scripts pueden lanzar `claude -p`, abrir un servidor HTTP local, terminar el proceso que ocupa ese puerto y escribir workspaces | documentar; ejecutar solo por petición explícita y con revisión humana |
| limitación | `skills` 1.5.21 requiere Node `>=22.20.0`, pero la plantilla soporta Node 18 | no convertir el CLI en dependencia de runtime; instalar por copia fijada |
| sin verificar | `npx skills` no terminó de resolver el paquete en esta máquina | se usó el instalador oficial de Codex por Git; repetir el comando npx en CI Node 22 antes de una actualización |

## Contrato adoptado

- Carpeta y `name`: kebab-case, coincidentes, máximo 64 caracteres.
- `description`: obligatoria, máximo 1024 caracteres, describe qué hace y cuándo se usa.
- Frontmatter canónico: `name`, `description`, `license`, `compatibility`, `metadata` y
  `allowed-tools`; las extensiones de host viven en el adaptador del host.
- `SKILL.md` por debajo de 500 líneas como recomendación; el detalle pasa a `references/`.
- Scripts autocontenidos o con dependencias explícitas; referencias relativas a la raíz de la skill.

## Cadena de suministro de skill-creator

- Publicador: Anthropic, repositorio oficial.
- Pin: `b29e7cf65e5cb78a5ac33d582270551bc74a14eb`.
- Licencia: Apache-2.0, incluida como `LICENSE.txt`.
- Scripts: Python; no usan `shell=True`. Los subprocesos observados son `claude -p` y `lsof`;
  el visor solo escucha en localhost. Las escrituras se dirigen a workspaces/rutas de salida.
- Actualización: revisar diff completo contra un commit nuevo y repetir gates; nunca seguir `main`.
- Normalización local: se eliminaron dos espacios finales en scripts Python para cumplir
  `git diff --check`; no cambia instrucciones, lógica ni artefactos de la skill oficial.

## Comando reproducible equivalente

Requiere Node 22.20 o superior:

```powershell
npx --yes skills@1.5.21 add https://github.com/anthropics/skills/tree/b29e7cf65e5cb78a5ac33d582270551bc74a14eb/skills/skill-creator --skill skill-creator --agent universal --copy --yes
```

La plantilla distribuye la copia versionada y el adaptador Claude; ningún proyecto consumidor
necesita ejecutar este comando para usarla.
